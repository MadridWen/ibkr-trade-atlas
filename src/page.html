行情与数据口径

自动依次尝试 Yahoo Finance、已配置的 Twelve Data、Nasdaq 和 Stooq。均为历史日线，可能延迟、缺失或限流。备用源复权未核实时只显示参考 K 线，不叠加成交标记、不计算浮盈亏。行情服务只接收股票代码与日期；成交记录保存于本站私有存储，不发送给行情服务。

行情币种必须与成交币种相同。仅接受股票 / ETF 数据。自动数据按已返回拆股事件还原为成交当时的价格单位，未对现金股息复权；FIFO 同步调整剩余批次的股数和单位成本。公司行动仍可能缺失，请以券商对账单核对。

Twelve Data 可指定未复权价格。管理员可在 Sites 环境变量中配置 TWELVE_DATA_API_KEY；密钥仅在服务端使用。日线及拆股接口需同时可用才参与估值。

表头 Symbol,Date,Open,High,Low,Close,Volume（Symbol 可选；有此列时会核对股票）。日期为交易所本地交易日，单位为当前成交币种；请使用未复权原始价，不要使用 Adj Close。导入行情会替换当前股票行情。

从成交到复盘

01 / 导入

中英文 Activity CSV（含 .plain / .txt）或逐笔 Flex。方向由 Buy/Sell 或带符号 Quantity 识别。佣金从 IBKR 负支出格式转为正费用；标准模板 Fee 为正支出。多账户匿名后分别配对，不保存账户号码。

02 / 看图

亮蓝色 ▲ B「买入」、金黄色 ▼ S「卖出」；标记加大并带文字标签，和低饱和绿色 K 线分开。位置对应实际成交价。悬停查看日线及当日成交，点击成交行高亮并展开 FIFO。选择股票、日期或快捷区间，缩小范围看清标记。

03 / 计算

买入不会确认已实现盈亏；区间没有卖出时该项为 0。按账户、股票、币种，以完整已导入历史按时间 FIFO 配对。净收益 = 卖出金额 − 分摊卖出费用 − 配对买入成本（含买入费用）。浮盈亏 = 期末持仓 × 区间末可用收盘价 − 期末成本。日期筛选不重置成本。

04 / 边界

支持持仓与已清仓股票；左侧“全部 / 持仓 / 已清仓 / 待核对”筛选不删除任何成交。仅支持股票 / ETF 的多头复盘。先卖后买、缺失买入的卖出部分不计收益，界面标注未匹配。USD 口径不含汇率影响；CNY 口径见组合总计说明。不含股息、利息、转仓及税务调整；缺少成本的收益显示“待核对”，不会把已匹配部分当作总收益。不等同于 IBKR 税务批次或总回报。自动行情未加载时拆股口径未核验。

隐私：Sites 私有访问，云端按你的登录身份隔离保存成交记录，同一账号跨设备可读取。上传的原始文件只用于解析；云端保留规范化的股票成交、换汇及美元资金流水，不保存原文件、姓名或地址。浏览器保留一份缓存，清理缓存不会删除已保存的云端成交。导出复盘仅包含当前股票与日期范围的标准成交和计算结果，并非完整备份；原始 IBKR 文件请自行保留。去重优先使用成交 ID；无 ID 时比较账户、股票、时间、方向、数量、价格与费用。相同时间的不同成交不会删除。成交 ID 内容冲突时整批不写入，并提示核对。行情请求经过本站代理，无第三方分析脚本。

时间：保留报表中的交易日期和时间，不做时区转换。请把报表时间设为对应市场交易所时区；跨市场记录请先校准。缺少时分秒时按同日文件顺序匹配。
